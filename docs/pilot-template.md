# Field pilot evidence template

**No field pilot has been conducted as part of this repository release work.**

For each consenting developer / repository, log:
- repo type and version, anonymized if needed
- tool/model version, commit SHA, date, tested agent
- task identifier, baseline vs specialized instructions and prompt order
- task completion time, token cost where obtainable, developer ratings
- confirmed true positives, false positives, unresolved claims and evidence grade (0–2)
- privacy/safety incidents, failures, retry attempts and feedback
- reproducible change proposed or adopted, and whether tests passed

Use at least 2–3 separate repositories. Do not publish customer code or credentials. Results must be independently reviewed before attributing productivity gains.
